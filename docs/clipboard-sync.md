# popMind 剪贴板同步（Cloudflare R2）设计文档

> 状态：第一期已实现（v0.4.0）
> 日期：2026-10-10
> 范围：第一期，仅 Mac 与 Mac 之间同步，手动触发。手机端不在计划内。

---

## 1. 需求（已确认）

1. 第一期只支持**手动同步**：剪贴板面板右上角放一个同步图标，点击后转圈，完成后弹出提示。
2. 只在电脑之间同步。
3. 可以接受延迟（手动触发，本身就不实时）。
4. 要记录每条内容是否已同步，已同步过的不再重复上传。
5. 收藏分组（Pinboard）也同步。同步是在当前设备上**新增**，不替换、不删除本地内容。
6. 同步过来的内容按"新内容"处理，不同步时间信息。
7. 本地文件 / 文件夹不同步。
8. 配置尽量简单：只粘贴一串密钥即可使用；同时提供一段"给 Agent 的提示词"，让 Agent 用 `cf` CLI 自动完成 Cloudflare 侧的配置。

## 2. 总体方案

- 数据存放在**用户自己 Cloudflare 账号下的 R2 存储桶**里。popMind 通过 R2 的 S3 兼容接口直接读写，不部署任何服务端，开发者也不经手用户数据。
- **端到端加密**：内容在本机加密后才上传。Cloudflare 只能看到密文和无意义的文件名。
- 用一串**同步密钥**包含全部配置。第一台设备生成密钥，其他设备粘贴同一串密钥即可加入。

### 2.1 同步密钥

```
pmsync1.<base64url(JSON)>
JSON = { a: accountId, b: bucket, k: accessKeyId, s: secretAccessKey, e: encryptionKey(32 字节随机, base64url) }
```

- 保存时使用 Electron `safeStorage`（macOS 钥匙串加密），不以明文写入设置文件。
- 设置页只显示密钥的前几位；提供"复制同步密钥"，方便在另一台设备上粘贴。

### 2.2 R2 凭证从哪来

Cloudflare 官方规则：R2 的 S3 `Access Key ID` = API Token 的 `id`，`Secret Access Key` = Token 值的 SHA-256。
所以只要有一个带 R2 权限的 Token，就能得到全部凭证。

## 3. 用户配置流程

### 3.1 方式 A：交给 Agent

设置页「复制提示词」（`lib/clipboard/sync/agent-prompt.ts`）。Agent：

1. `cf auth whoami` 检查登录，未登录让用户 `! cf auth login`。
2. 确定账户 ID；用 `cf r2 buckets create` 创建 `popmind-sync`（已存在且有 `meta/check` 则停止，让用户去已同步的设备复制密钥）。
3. `cf` 的 OAuth 登录**没有创建 API Token 的权限**（实测 `/user/tokens` 返回 403），所以由用户在 R2 后台创建「对象读和写」令牌（只限该存储桶），把「访问密钥 ID」和「机密访问密钥」交给 Agent。
4. Agent 用提示词里的 `node -e` 命令本地生成加密密钥并拼出 `pmsync1.…`，交给用户粘贴到「连接同步」。

### 3.2 方式 B：手动

1. Cloudflare 后台 → R2 → 管理 API 令牌 → 创建"管理员读和写"令牌。
2. 在 popMind 中粘贴**令牌值 + 账户 ID**。
3. popMind 自动完成剩余步骤：校验令牌并取得 `id`，推算 S3 凭证，创建存储桶，生成加密密钥，最后给出完整的同步密钥（供其他设备使用）。

### 3.3 其他设备

只需粘贴同步密钥。粘贴后先做一次连通性检查（列出存储桶内容并解密一个对象），失败时给出明确原因：密钥格式错误、凭证无效、存储桶不存在，或加密密钥不匹配。

## 4. 同步范围

### 4.1 同步

| 内容 | 说明 |
| --- | --- |
| 文字、富文字、链接、颜色 | 纯文本 + HTML / RTF 表示 |
| 图片 | 只传 PNG 原图（单张超过上限则跳过，默认 10 MB） |
| 自定义标题 | 用户自己写的内容 |
| 来源应用 | 只传 bundleId + 名称，图标在本机重新获取，取不到时用默认图标 |
| 收藏分组 | 名称 + 颜色 + 组内有哪些条目 |

### 4.2 不同步

| 内容 | 原因 |
| --- | --- |
| 文件 / 文件夹条目 | 存的是本机路径，另一台电脑上不存在 |
| 从其他设备同步来的条目 | 避免来回重复上传 |
| 已删除（回收中）的条目 | 用户已经不要了 |
| 时间与使用统计（复制时间、使用时间、复制 / 使用次数） | 需求 6：同步来的内容算新内容 |
| OCR 文字、缩略图、本地标签 / AI 标签、富化任务状态 | 可在本机重新生成，没必要占流量和存储 |
| 应用图标、文件图标缓存 | 同上 |
| 设置项（隐私规则、忽略的应用、快捷键、保留策略等） | 每台电脑可能不同，第一期不做 |
| 暂停记录状态、Paste Stack | 临时状态 |
| 收藏分组的排序 | 两台设备各自排序，新增的分组排在末尾 |
| 删除 / 修改操作 | 需求 5：同步只新增。本地删除不会删远端，远端已有的内容也不会被覆盖 |

### 4.3 首次同步上传多少历史

默认：**收藏分组里的全部条目 + 开启同步前 7 天的历史**；开启同步之后复制的内容都会上传。
设置「同步」页可改为最近 30 天 / 全部历史 / 不上传历史，图片大小上限默认 10 MB。

## 5. 远端数据结构（存储桶内）

所有对象名都是**带密钥的哈希**（HMAC-SHA256），内容一律 AES-256-GCM 加密。

```
items/<hmac(fingerprint)>     单条内容：{v, kind, subKind, isRich, customTitle, plainText, html, rtf, url, colorValue, source, imageRef}
blobs/<hmac(imageHash)>       图片 PNG
pinboards/<hmac(name)>        分组：{v, name, color, items: [itemKey...]}
meta/check                    加密的固定字符串，用来校验加密密钥是否正确
```

- 对象名由**内容指纹**推算。两台设备复制了同一段内容，对应的是同一个对象，远端天然不会重复。
- 分组以**名称**为标识。两台设备上的同名分组会合并，组内条目取并集。

## 6. 同步流程（点击同步图标后）

1. **拉取**：分页列出 `items/` 和 `pinboards/`，与本地 `sync_remote_keys` 表对比，只下载本地没有的对象。
   - 解密后按指纹去重：本机已有相同内容，只记录对应关系，不新增条目。
   - 新条目的复制时间统一设为本次同步时间，同一批内容保持远端上传的先后顺序。
   - 标记为"来自同步"（`sync_origin = 'remote'`），以后不会再上传。
   - 合并分组：本地没有的同名分组就新建，再把条目加进去（只增不减）。
2. **上传**：找出本地"未同步且符合范围"的条目，加密后上传（并发 4–8 个）；图片先查远端是否已有，没有才上传。成功一条就标记一条，中途失败下次可以接着传。
3. 上传有变化的本地分组。
4. 完成后提示：`已同步 · 收到 12 条，上传 30 条`；失败时提示原因（网络、凭证、加密密钥不匹配等）。

同一时间只允许运行一次同步；面板关闭不会中断同步。

## 7. 本地改动

- 新增表（不提升 `user_version`，每次打开数据库 `CREATE TABLE IF NOT EXISTS`，旧版本 App 共用同一数据库也不受影响）：
  - `sync_items(item_id PK, remote_key, origin 'local'|'remote'|'skipped', synced_at)`：记录每条内容是否已同步，以及它对应的远端对象
  - `sync_remote_keys(remote_key PK, seen_at)`：已经见过的远端对象，本机删除后不会再被下载回来
  - `sync_pinboard_members(pinboard_key, item_key)`：已应用过的分组成员，本机移出分组后不会再被加回来
- `lib/clipboard/sync/`：`r2-client.ts`（基于 `fetch` 的 SigV4 签名 + 断线 / 5xx 自动重试，不引入 AWS SDK）、`sync-crypto.ts`、`sync-key.ts`、`sync-payload.ts`、`sync-engine.ts`、`sync-state.ts`（钥匙串加密保存同步密钥）、`index.ts`
- IPC：`clipboard.sync.run / status / configure / disconnect / getPrompt`，契约放在 `lib/conveyor/schemas/clipboard-schema.ts`
- UI：
  - 面板 `TopBar` 右上角放同步图标（lucide `RefreshCw`，14px）；同步中图标旋转；结果用面板里现有的提示样式显示；未配置时点击跳转到设置页的同步部分
  - 设置页"剪贴板"下新增"同步"小节：粘贴密钥、复制提示词、手动配置、最近同步时间、断开同步

## 8. 费用

R2 免费额度：存储 10 GB / 月，写类操作 100 万次 / 月，读类操作 1000 万次 / 月，流量免费。个人手动同步远低于这些额度，正常使用不产生费用。
