# 待办专注重构方案

> 日期：2026-09-30
> 范围：启动器 `/todo` 面板（820×540 窗口内）

## 1. 现状问题

1. **名为"待办专注"，但没有专注功能**：插件描述是"把专注番茄直接绑定到任务上"，代码里只有待办清单
2. **照搬桌面待办应用的布局**：可折叠侧边栏 + 迷你日历 + 大输入卡片，挤在 820×540 的启动器里
3. **添加任务要点很多次**：日期、标签、优先级各有一个弹出控件；启动器搜索框里的文字和面板里的输入框重复
4. **没有键盘操作**：启动器是键盘优先的场景，但面板只能用鼠标
5. **数据只在渲染层 localStorage**：启动器收起时面板被销毁，任何计时都无法延续
6. 文案写死中文，没有国际化

## 2. 参考产品

| 产品 | 借鉴点 |
| --- | --- |
| Things 3 | 今天 / 计划 / 收集箱 / 已完成 四个视图；今天视图里逾期任务置顶标红；计划视图按日期分组；简洁的圆形勾选框 |
| Todoist | 快速添加的自然语言解析：`明天 下午3点 写周报 #工作 !1`，识别出的日期、标签、优先级实时高亮 |
| TickTick / Session / Flow | 番茄专注绑定任务；专注中菜单栏显示倒计时；结束时系统通知；自动进入休息；记录每个任务的专注时长和番茄数 |
| Raycast | 启动器里的列表 + ⌘K 操作菜单；所有操作都有快捷键并在菜单里显示 |

## 3. 交互设计

### 3.1 布局

```
┌ 启动器搜索框：/todo 明天 3pm 写周报 #工作 !1 ───────────────────────────────┐
├──────────────────────────────────────────────────────────────────────────────┤
│ [今天 3] [计划] [收集箱 2] [已完成]                 今日专注 50 分钟 · 2 🍅  ⚙ │
├──────────────────────────────────────────────────────────────────────────────┤
│ ＋ 写周报     明天 15:00  #工作  !1                                  ↩ 添加  │  ← 输入时出现
│ ┌ 专注中 ─────────────────────────────────────────────────────────────────┐ │  ← 专注时出现
│ │ ◔ 18:42  设计评审准备           第 2 个番茄      [暂停] [完成任务] [结束] │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
│ 逾期                                                                          │
│ ○ 回复客户邮件                                       9月28日   🍅 1/2        │
│ 今天                                                                          │
│ ○ 设计评审准备                               15:00  #产品     🍅 2/4   ▶     │  ← 选中行
│ ○ 买咖啡豆                                                                    │
├──────────────────────────────────────────────────────────────────────────────┤
│ ↩ 开始专注   ⌘↩ 完成   ⌘E 编辑   ⌘K 更多操作                                 │  ← 选中时的操作提示
└──────────────────────────────────────────────────────────────────────────────┘
```

- 去掉侧边栏和迷你日历；视图切换改成顶部分段控件（⌘1–⌘4）
- **启动器搜索框就是快速添加框**：`/todo` 后面输入的文字实时解析，列表顶部显示预览行，回车添加
- 专注进行中时，列表上方固定一张专注卡片
- 底部一行浅灰小字显示当前可用的快捷键（启动器里的常见做法）

### 3.2 快速添加（自然语言）

| 写法 | 含义 |
| --- | --- |
| `今天` `明天` `后天` `周一`…`周日` `下周三` `3月12日` `3/12` `tomorrow` `mon` | 日期 |
| `15:00` `3pm` `下午3点` `晚上8点半` | 时间 |
| `#工作` | 标签（可多个） |
| `!1` `!2` `!3` 或 `p1` `p2` `p3` | 优先级（1 最高） |
| `~2` | 预计番茄数 |

识别到的部分在预览行里显示为标签；添加后标题只保留其余文字。在"今天"视图添加且没写日期时，默认今天。

### 3.3 键盘操作

焦点始终在启动器搜索框。

| 按键 | 搜索框有文字 | 搜索框为空 |
| --- | --- | --- |
| ↩ | 添加任务 | 对选中任务开始专注 |
| ↑ ↓ | 选择任务 | 选择任务 |
| ⌘↩ | — | 完成 / 取消完成 |
| ⌘E | — | 编辑 |
| ⌘T / ⌘⇧T | — | 设为今天 / 推迟到明天 |
| ⌘⌫ | — | 删除（可撤销） |
| ⌘K | — | 操作菜单 |
| ⌘1–⌘4 | 切换视图 | 切换视图 |
| ⌘P | 暂停 / 继续专注 | 暂停 / 继续专注 |

中文输入法组词期间不响应。鼠标：点圆圈完成，悬停出现 ▶ 开始专注，双击编辑，右键同 ⌘K。

### 3.4 专注（番茄钟）

- 默认 25 分钟专注、5 分钟短休息、每 4 个番茄一次 15 分钟长休息，可在 ⚙ 里改
- 计时在主进程运行：启动器收起后继续计时
- 菜单栏图标旁显示剩余时间（`18:42`），暂停时显示 `⏸ 18:42`
- 专注结束：系统通知 + 提示音，给任务记 1 个番茄和专注分钟数，自动开始休息（可关）；休息结束通知，不自动开始下一个
- 中途结束：已专注满 1 分钟的计入专注时长，但不计番茄
- 专注卡片按钮：暂停 / 继续、完成任务（同时结束专注并记录）、结束；休息时显示"跳过休息"
- 顶部显示今日专注总分钟数和番茄数

### 3.5 编辑

⌘E 或双击打开编辑弹窗：标题、备注、日期（今天 / 明天 / 下周一 / 清除 + 日期选择）、时间、优先级、标签、预计番茄数；并显示该任务累计专注时长。

## 4. 技术方案

- **数据**：主进程 JSON 存储 `userData/todo-focus.json`（任务、最近 90 天专注记录、专注设置），写入先写临时文件再改名，防止损坏；首次启动时把旧 localStorage 数据导入
- **主进程**：`lib/todo-focus/`：`store.ts`（读写）、`focus-service.ts`（计时状态机、通知、菜单栏标题）、`types.ts`、`parse.ts`（自然语言解析，渲染层共用）、`dates.ts`
- **IPC**：`lib/conveyor/schemas/todo-schema.ts` + api + handler；推送通道 `todo:state`（任务变化）、`todo:focus`（专注状态每秒不推送，只推状态变化，倒计时由渲染层根据 `endsAt` 自行计算）
- **渲染层**：`app/components/todo-focus/` 拆成视图、列表行、快速添加预览、专注卡片、编辑弹窗、操作菜单
- **文案**：`lib/todo-focus/i18n.ts`（中英文）
- **UI**：遵循 `AGENTS.md` 的 macOS 原生风格规范
