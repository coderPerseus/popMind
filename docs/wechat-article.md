# 选中文字，AI 秒懂 —— popMind，你桌面上最趁手的 AI 阅读助手

你有没有过这样的体验？

读英文文档时看到一个不认识的词，切到翻译软件查一下，再切回来——思路断了。看技术博客时遇到一段代码不理解，复制到 ChatGPT 问一嘴，等回来的时候已经忘了上下文。浏览器里开了十几个标签页，效率工具装了一堆，结果最消耗时间的，是"切换"本身。

**popMind 想解决的就是这个问题：让你不离开当前阅读的内容，就能翻译、解释、提问。**

---

## 一句话介绍

popMind 是一款 macOS 桌面 AI 工具。选中任意文字，浮窗即时翻译或 AI 解释，无需切换窗口，阅读和理解在同一个画面里完成。

---

## 它能做什么？

### 1. 选中即触发

在任何应用里选中一段文字，popMind 会在旁边弹出一个小气泡，提供四个动作：

- **翻译** —— 立即弹出浮窗翻译，不用离开当前页面
- **解释** —— AI 生成一段通俗易懂的解释，还能继续追问
- **问 AI** —— 把选中的文字作为上下文，你再补一句问题，AI 结合语境回答
- **复制** —— 最朴素但最常用的操作

不需要打开任何额外窗口，不需要复制粘贴到别的地方，**选中就能用**。

### 2. 六大翻译引擎，一键切换

内置了 Google、DeepL、Bing、有道、AI 翻译和本地 Gemma 模型翻译，随时切换。

其中有道引擎对英文单词特别友好——音标、释义、词组、例句一应俱全，查词体验堪比专业词典。AI 翻译则使用你配置的大语言模型来翻译，对长句和专业术语的理解更准确。

翻译窗口支持钉住、调整大小，不会挡住你正在阅读的内容。

### 3. AI 解释 + 追问，不只是翻译

翻译只是起点。点击"解释"，popMind 会调用你配置的 AI 模型（支持 OpenAI、Claude、Gemini、DeepSeek、Kimi）生成一段解释，而且：

- **感知上下文**：自动携带当前应用名称，甚至可以截取源窗口的截图，让 AI 理解你在看什么
- **联网搜索增强**：可选配置 Tavily、Serper、Brave 等搜索引擎，让回答有据可查
- **流式输出**：打字机效果，边生成边阅读，不用干等
- **支持追问**：在同一个会话里继续提问，AI 记得之前的对话

一个典型场景：你在看一篇英文论文，选中一段方法描述，先翻译看大意，觉得没完全理解，点"解释"让 AI 用大白话说一遍，然后追问"这个方法和 XXX 有什么区别？"——全程不离开论文页面。

### 4. 主窗口：你的快捷指令中心

除了选中触发，popMind 还有一个主窗口，用斜杠命令快速操作：

| 命令 | 功能 |
|------|------|
| `/tr` 或 `/翻译` | 翻译文本 |
| `/ex` 或 `/解释` | AI 解释文本 |
| `/cal` | 计算器，直接输入算式得结果 |
| `/todo` | 待办 + 专注计时 |
| `/chatgpt` | 跳转 ChatGPT 并携带内容 |
| `/perplexity` | 跳转 Perplexity 搜索 |
| `/google` | 跳转 Google 搜索 |

不输入命令时，主窗口还可以搜索并启动 Mac 上已安装的应用。

### 5. 剪贴板历史

内置剪贴板历史管理器，自动记录你复制过的文字、图片、文件、链接、颜色值，支持搜索、筛选、置顶和快速粘贴。再也不用担心"刚才复制的那段话去哪了"。

### 6. 隐私友好：支持本地模型

如果你不想把内容发送到云端，popMind 支持通过 LM Studio 接入本地 Gemma 模型，翻译和对话全部在本地完成，数据不出你的电脑。

## 为什么选 popMind？

市面上翻译工具和 AI 助手不少，popMind 的不同在于：

**选中即用，零切换成本。** 不是"打开一个 App 然后粘贴"，而是"选中文字就出现在旁边"。这个交互差异看起来很小，但用起来是质的区别——你的注意力始终在你正在阅读的内容上。

**翻译和 AI 理解一体化。** 不是只翻译或只对话，而是两者无缝衔接。遇到不认识的词用翻译，遇到不理解的概念用 AI 解释，遇到想深入的问题接着追问——工具随内容而变，而不是内容迁就工具。

**你选择用哪个 AI。** 支持 OpenAI、Anthropic Claude、Google Gemini、DeepSeek、Kimi 五家 AI 服务商，用你自己的 API Key，不绑定任何平台。

**桌面原生体验。** 不是 Chrome 插件，不是网页应用，而是真正的桌面应用。托盘菜单、全局快捷键、浮窗钉住、窗口自动管理，为 macOS 深度优化。
